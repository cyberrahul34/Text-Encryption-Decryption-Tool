# Text-Encryption-Decryption-Tool

Text Encryption & Decryption Tool
A simple Python application to demonstrate how text can be encrypted
and decrypted using cryptography.

Developer: Rahul Kumar
Course: Cyber Security
Project Type: Personal / Individual Project
About the Project
The Text Encryption & Decryption Tool is a beginner-friendly Python
project that demonstrates how readable text (plaintext) can be converted
into encrypted text (ciphertext), and then restored to its original form
through decryption.

The project demonstrates two methods:
1. Caesar Cipher -- a basic classical cipher that shifts alphabetic
   characters by a selected number of positions. It is included for
   learning purposes only.
2. Fernet Encryption -- a modern, authenticated symmetric
   encryption method provided by the Python cryptography library.
The project helps explain important cyber security concepts such as
confidentiality, plaintext, ciphertext, encryption, decryption, and
secret-key management.
Features
- Encrypt text using Caesar Cipher.
- Decrypt Caesar Cipher text using the same shift value.
- Encrypt text using Fernet.
- Decrypt Fernet tokens using the matching secret key.
- Generate and save a Fernet key in key.key (if the program is
  written to do so).
- Save encrypted output in encrypted.txt (if enabled in the
  program).
- Simple command-line interface.
Technologies Used
- Language: Python 3
- Library: cryptography (Fernet)
- Editor used: Visual Studio Code
- Interface: Command Line / Terminal
Requirements
- Python 3 installed on your computer.
- Internet connection for installing the dependency.
- A terminal such as PowerShell, Command Prompt, or the VS Code
  integrated terminal.
Installation
1. Download or clone this project.
2. Open the project folder in a terminal.
3. Install the required Python library:
   python -m pip install cryptography
4. Run the Python file. Replace encryption.py with the actual name of
   your script if it is different:
   python encryption.py
How to Use
1. Start the program.
2. Select the encryption method shown in the menu.
3. Enter the text you want to test.
4. For Caesar Cipher, enter a shift value when prompted.
5. Read the encrypted output.
6. Check the decrypted output to confirm that it matches the original
   message.
For Fernet, the same secret key must be used to decrypt a token. Keep
the generated key.key file safe if you need to decrypt saved tokens
later.
Example
Caesar Cipher
Original text : HELLO
Shift         : 3
Encrypted     : KHOOR
Decrypted     : HELLO
Fernet
Original text : Hello Rahul
Encrypted     : [Fernet token - different each time]
Decrypted     : Hello Rahul
The Fernet token is generated by the program. Its exact value can differ
each time encryption is performed.

Security Notes
- Caesar Cipher is not secure. It can be broken easily and must
  only be used for learning.
- Fernet is the recommended method in this project for demonstrating
  modern authenticated encryption.
- Keep key.key private. Anyone who has both the key and the
  encrypted token can decrypt the message.
- Do not delete or replace the key if you still need to decrypt tokens
  created with it.
- Do not upload your real secret key to GitHub or share it publicly.
- This project is an educational demonstration, not a complete secure
  messaging or password-storage product.
- Do not enter real passwords, banking details, or other sensitive
  information into a demonstration program.
